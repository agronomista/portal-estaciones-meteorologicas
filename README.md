# Portal de estaciones meteorológicas

Portal web educativo para que estudiantes comparen tres estaciones meteorológicas según:

- variables disponibles;
- sensores instalados;
- resolución temporal;
- pertinencia para el objetivo del análisis.

## Estaciones incluidas

1. Estación meteorológica Davis
2. Estación meteorológica de malezas
3. Estación meteorológica IMN–FBM

## Sitio web

El portal utiliza `index.html` como página principal y puede publicarse mediante GitHub Pages desde la rama `main` y la carpeta raíz del repositorio.
